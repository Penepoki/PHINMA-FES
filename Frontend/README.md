# Environment Variable creation tutorial:
## Tutorial for creating an enviroment variable for local:
### 1. Create a .env file, you can run this in terminal or create it by explorer:
If by terminal:
```
cp .env
```

### 2. Then inside the file input your address:
```
VITE_API_BASE_URL="localhost_address"
```

## Tutorial for creating environment variable for production:
### 1. Create a .env.production, by terminal or manual creation:
If by terminal:
```
cp .env.production
```

### 2. Inside .env.production input your address:
```
VITE_API_BASE_URL="yourexampledomain.com"
```
